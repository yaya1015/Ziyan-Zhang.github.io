# 张紫砚 · Ziyan Zhang

安徽大学学术主页。双击 `index.html` 即可本地预览。网站使用静态 HTML、Jemdoc 样式和本地照片，无需安装依赖。

## 发布到 GitHub Pages

1. 在 GitHub 上打开你的个人主页仓库。如果还没有仓库，新建一个名为 `<GitHub 用户名>.github.io` 的公开仓库，并勾选 **Add README** 来初始化分支。
2. 在仓库的 **Code** 页面点击 **Add file → Upload files**。从本目录拖入 `index.html`、`jemdoc.css`、`EnHome.html`、`.nojekyll` 和整个 `picture` 文件夹，然后提交到 `main`。上传后，`index.html` 应位于仓库根目录，照片路径应为 `picture/photo-zzy.jpg`。
3. 在仓库的 **Settings → Pages** 中，选择 **Deploy from a branch**，将发布源设为 **main → / (root)** 并点击 **Save**。如果仓库已经启用了 Pages，请把文件提交到当前的发布分支和目录。
4. 部署完成后，在 **Settings → Pages** 点击 **Visit site**。如果仓库名为 `<GitHub 用户名>.github.io`，默认网址就是 `https://<GitHub 用户名>.github.io/`。

[GitHub Pages 官方说明](https://docs.github.com/en/pages/quickstart)

## 更新主页

编辑 `index.html` 中对应的栏目。论文标题链接到 DOI、会议官网或 arXiv。照片位于 `picture/photo-zzy.jpg`。
